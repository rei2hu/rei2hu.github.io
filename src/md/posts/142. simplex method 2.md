# simplex method 2

This is a semi-continuation of [simplex method 1](/posts/137).

Here, I'll attempt to build a chain of reasoning to the simplex method, though
it's not a true attempt because I have a small inclination of how it works due
to learning about it previously. Also I may make basic math mistakes.

To recall, we're trying to maximize $23x + 12y$ given the following set of
constraints.

$$
\begin{aligned}
    x + y &\leq 24 \\
    2x + 3y &\geq 40 \\
    5x + 10y &\leq 200 \\
    20x + 5y &\leq 300
\end{aligned}
$$

$$
x \geq 0, y \geq 0
$$

And the way we did this was to visually plot the inequalities to determine a
feasible region, pick points that correspond corners of that region, and then
slot those points into the equation we're trying to maximize. Specifically, the
points were (0, 20), (8, 16), (12, 12), (14, 4), (0, 13.3), and it was maximized
at (12, 12).

To handle this in a non-visual way, we need to figure out the following:

1. We need to be able to find a point within the feasible region easily.
2. Given a point in the region, we need to determine how to "slide" along the
   constraints that the point is for.

I'll start with #2. Let's say we already somehow figured out how to pick a
point, and the point is (8, 16). If we're trying to maximize $23x + 12y$, then
it makes sense to add more $x$s if possible, since that has the highest
co-efficient.

How many $x$s can we add? That depends on the constraints. If we plug our
numbers into the original set of constraints, we can find the inequalities that
are bounding our point.

$$
\begin{aligned}
    (8) + (16) &\leq 24 \\
    2(8) + 3(16) &\geq 40 \\
    5(8) + 10(16) &\leq 200 \\
    20(8) + 5(16) &\leq 300
\end{aligned}
$$

$x + y \leq 24$ and $5x + 10y \leq 200$. This means that we will want to "slide"
against one of those constraints to find a new corner point - but which one?

For this, we want to look at the other inequalities and figure out how much room
we have to move and if it's going to be valuable. For one, we have \$2(8) +
3(16) - 40 = 24$, and the other we have $300 - 20(8) + 5(16) = 60\$. This is
called "slack".

This is about to get pretty hand-wavy in my opinion (curse of knowledge), but...

In fact, we should introduce slack variables for all our inequalities, as they
represent how far we can go in each direction. In this case $s_2 = 24$,
$s_4 =
60$, and $s_1 = s_3 = 0$ because the first and third equations are what we
are currently constrained to.

$$
\begin{aligned}
    x + y &\leq 24 &\Rightarrow   &x + y + s_1 = 24 \\
    2x + 3y &\geq 40 &\Rightarrow   &2x + 3y - s_2 = 40 \\
    5x + 10y &\leq 200 &\Rightarrow   &5x + 10y + s_3 = 200 \\
    20x + 5y &\leq 300 &\Rightarrow   &2x + 3y + s_4 = 300
\end{aligned}
$$

Note that we are not actually substituting the slack variables in. And what
we're trying to do is maximize the original function by adding slack to $s_1$ or
$s_3$ while consequently reducing it for $s_2$ and $s_4$. To do this, we can
rewrite the function in terms of $s_1$ and $s_3$ by solving for $x$ and $y$
using our current constraint equations (the first and third). Just subtract the
equations from multiples of each other to cancel out a variable and you end up
with

$$
\begin{aligned}
    x = 8 - 2s_1 + \frac{s_3}{5} \\
    y = 16 + s_1 - \frac{s_3}{5}
\end{aligned}
$$

Substituting that into $23x + 12y$ gives

$$
376 - 34s_1 + \frac{11}{5}s_3
$$

This means we can increase the value of this by adding slack to $s_3$, that is,
we keep ourself constrained to the first inequality $x + y \leq 24$. But which
new constraint do we pick?

We can ignore $2x + 3y$ because it's a greater than inequality, which allows us
to add as many $x$s and $y$s as we want (similar for the simple $\geq 0$
inequalities).

We're also ignoring $5x + 10y \leq 200$ because we're going away from that
constraint.

This means we need to look at $20x + 5y \leq 300$. This allows us to add four
$x$s per $y$. However, we're still going to be constrained to the $x + y \leq
24$
inequality, so we want to find where these inequalities (as equalities)
intersect which happens to be (12, 12) which we know to be the solution.

But now the questions is why is (12, 12) the solution? Let's do the entire thing
we just did previously - write the function we're trying to maximize in terms of
slack variables, but at (12, 12).

We're constrained by the first and fourth inequalities now, so we want to have
$x$ and $y$ in terms of those.

$$
\begin{aligned}
    x = 12 + \frac{1}{3}s_1 - \frac{1}{15}s_4 \\
    y = 12 - \frac{4}{3}s_1 + \frac{1}{15}s_4
\end{aligned}
$$

$$
420 - \frac{25}{3}s_1 - \frac{11}{15}s_4
$$

Now that both coefficients are negative, we know that adding slack anywhere
available will now lower the value. We also see the maximum value is 420 which
we figured out last time.

While we did try this for corner points, this will in fact work for any point
within the region.

So now we know how to move around the points to corner points to the answer, but
how do we find an initial point to start at? The short answer is that usually
setting all variables to 0 should work, but I happened to write constraints in a
way that it doesn't... and requires a more complex method than what I was hoping
to write about. The specific thing issue is the $\geq$ comparison here, so let's
move on assuming it doesn't exist.

So we have a rough understanding of how to solve our problem in a non-visual
format, I'll now go over what I remember about how to actually do it. I'll share
the (objective) function and updated constraints again.

$$
23x + 12y
$$

$$
\begin{aligned}
    x + y &\leq 24 \\
    5x + 10y &\leq 200 \\
    20x + 5y &\leq 300
\end{aligned}
$$

$$
x \geq 0, y \geq 0
$$

As before, we change the inequalities to equalities with slack variables. This
time we also do the same with the objective function where $Z$ is the final
value. We shuffle things around so that all coefficients for the slack variables
and $Z$ are positive.

$$
\begin{aligned}
    x + y + s_1 &= 24 \\
    5x + 10y + s_2 &= 200 \\
    20x + 5y + s_3 &= 300 \\
    -23x + -12y + Z &= 0
\end{aligned}
$$

And dump it into a table called a tableau here columns are variable coefficients
and rows are equations. This represents the state of the solution at (0, 0)

| x   | y   | s1  | s2  | s3  | Z   | C   |
| --- | --- | --- | --- | --- | --- | --- |
| 1   | 1   | 1   | 0   | 0   | 0   | 24  |
| 5   | 10  | 0   | 1   | 0   | 0   | 200 |
| 20  | 5   | 0   | 0   | 1   | 0   | 300 |
| -23 | -12 | 0   | 0   | 0   | 1   | 0   |

Somewhat like we reasoned previously, if any of the coefficients of the final
row are negative (we said positive previously but due to shuffling things around
it's negative here), we can improve the value of the objective function by
picking the most negative column - $x$.

Now which constraint do we pick? Technically speaking, this wasn't covered
because 3 constraints at a corner points means there's nothing to pick, but
we're looking at the ratios here. We want to add $x$s, but can only do
$min(Z/x)$ or $min(15, 40, 24) = 15$. So now we're looking at 20 in column $x$
as the "pivot" element.

Now is the weird part. Since we've picked that spot, we now want to perform
transformations on this tableau so that that value is replaced with a 1, and the
other values in the column are 0s. Remember that these are just linear equations
so you can multiply an entire row and add/subtract them from each other.

| x   | y     | s1  | s2  | s3    | Z   | C   |
| --- | ----- | --- | --- | ----- | --- | --- |
| 0   | 3/4   | 1   | 0   | -1/20 | 0   | 9   |
| 0   | 35/4  | 0   | 1   | -1/4  | 0   | 125 |
| 1   | 5     | 0   | 0   | 1     | 0   | 300 |
| 0   | -25/4 | 0   | 0   | 23/20 | 1   | 345 |

What is this table representing? This represents (15, 0) which was not part of
the original problem due to the $\geq$ constraint, but anyways... We look at the
last row and see that $y$ has a negative coefficient still, which means we can
keep going, picking the 3/4 value to pivot on.

| x   | y   | s1    | s2  | s3    | Z   | C   |
| --- | --- | ----- | --- | ----- | --- | --- |
| 0   | 1   | 4/3   | 0   | -1/15 | 0   | 12  |
| 0   | 0   | -35/3 | 1   | 1/3   | 0   | 20  |
| 1   | 0   | -1/3  | 0   | 1/15  | 0   | 12  |
| 0   | 0   | 25/3  | 0   | 11/15 | 1   | 420 |

Finally we're at a point where none of the coefficients are negative, and we
know the solution is 420. If those coefficients look familiar, it's because
they're the same as what we calculated originally (though, again, signs are
flipped).

$$
420 - \frac{25}{3}s_1 - \frac{11}{15}s_4
$$
